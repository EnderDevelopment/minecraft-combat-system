# CombatSystem

CombatSystem is a Minecraft plugin designed to manage player combat interactions, providing a robust framework for tracking and handling combat events between players. This plugin is ideal for server administrators looking to implement custom combat mechanics, such as combat logging prevention, combat tags, or any other combat-related features.

## Install

1. Download the CombatSystem plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` directory of your Minecraft server.
3. Start or restart your Minecraft server to load the plugin.

## Use

1. Once the server is running with the CombatSystem plugin installed, players will automatically be tracked during combat interactions.
2. To check if a player is in combat, use the `/combat` command in-game.
